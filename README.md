# MyHome — 3D-макет дома

Визуализация дома по чертежам.

## Структура

- `drawings/` — чертежи (PDF, фото, сканы планов, фасадов, разрезов).
- `viewer/house.json` — модель дома: этажи, стены, окна/двери, комнаты, крыша.
- `viewer/index.html`, `viewer/main.js` — 3D-просмотрщик на three.js.

## Как посмотреть

```bash
cd viewer
python3 -m http.server 8000
# открыть http://localhost:8000
```

Мышь: левая кнопка — вращать, правая — сдвигать, колесо — зум.

## Модель

`viewer/house.json` собран по проекту 23/21-АС (планы 1-го и 2-го этажей, фасады, разрез 1-1, план кровли):
дом 15,6 × 9,1 м по осям, два этажа (второй — мансардный), двускатная кровля 45° с коньком на +8,500,
застеклённая веранда, терраса под свесом кровли, крыльцо, каменный дымоход, мансардные окна.

Упрощения: перегородки и лестница показаны приблизительно (лестница — прямым маршем),
подписи комнат берут площади из экспликации проекта.

## Формат `house.json`

Все размеры в метрах, высоты — абсолютные отметки (0.000 = чистый пол 1-го этажа).
План в координатах `[x, y]`: x — вдоль осей 1→5 (ось 1 = 0), y — от оси В (0) к осям Б и А.

- `floors[]` — этажи: `elevation` (отметка пола), `height` (высота стен по умолчанию),
  `slab` (толщина перекрытия под этажом), `outline` (контур перекрытия), `holes` (проёмы в перекрытии).
  - `walls[]` — стены по осям: `from`, `to`, `thickness`, `height`, `id`;
    `material: "glass"` — витраж; `clip` — какая группа скатов срезает стену сверху (по умолчанию `wallClip`).
  - `openings[]` — проёмы: `wall` (id стены), `type` (`window` / `door` / `glassdoor`),
    `offset` (от точки `from` стены до края проёма), `width`, `height`, `sill` (низ проёма над полом).
  - `rooms[]` — помещения: `name`, `polygon`, `color`, `area` (если не задана — считается), `label` (точка подписи).
- `roofs[]` — скаты: `corners` (4 угла нижней плоскости `[x, y, h]`), `thickness`, `color` или `material: "glass"`,
  `clip` (имя группы: стены этой группы обрезаются по скату, так получаются фронтоны), `windows` (мансардные окна `x`/`y`).
- `solids[]` — призмы (дымоход, терраса, столбы): `bottom: {rect: [x0, x1, y0, y1], h}` и `top` или `height`.
- `stairs[]` — прямой марш: `x`, `y` (от низа к верху), `h`, `steps`.
