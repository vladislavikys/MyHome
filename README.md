# MyHome — 3D-макет дома

Визуализация дома по чертежам.

## Структура

- `drawings/` — чертежи (PDF, фото, сканы планов, фасадов, разрезов).
- `viewer/house.json` — модель дома: этажи, стены, окна/двери, комнаты, крыша.
- `viewer/index.html`, `viewer/main.js` — 3D-просмотрщик на three.js.

## Как посмотреть

```bash
cd viewer
python3 -m http.server 8000
# открыть http://localhost:8000
```

Мышь: левая кнопка — вращать, правая — сдвигать, колесо — зум.

## Формат `house.json`

Все размеры в метрах. План в координатах `[x, y]`, начало — любой угол дома.

- `floors[]` — этажи: `elevation` (отметка пола), `height` (высота стен), `slab` (толщина перекрытия).
  - `walls[]` — стены по осям: `from`, `to`, `thickness`, необязательный `id`.
  - `openings[]` — проёмы: `wall` (id стены), `type` (`door` / `window`),
    `offset` (расстояние от точки `from` стены до края проёма), `width`, `height`, `sill` (высота подоконника).
  - `rooms[]` — комнаты: `name`, `polygon` (контур пола), `color`. Площадь считается автоматически.
- `roof` — крыша: `type: "gable"` (двускатная), `pitch` (уклон, °), `overhang` (свес), `color`.

Сейчас в `house.json` — пример; по чертежам из `drawings/` он заменяется реальными размерами.
